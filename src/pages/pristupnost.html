Jak je web přístupný

Web je navržen podle mezinárodních pravidel přístupnosti WCAG 2.2 na úrovni AA. Text má vysoký kontrast, dá se zvětšit až na 400 % a web se ovládá i klávesnicí. Nepoužíváme žádné sledovací nástroje.
